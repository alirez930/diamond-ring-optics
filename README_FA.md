# مجموعه نسخه‌های شبیه‌سازی Diamond Ring Optics

این آرشیو شامل فایل‌های HTML قابل اجرا و بسته‌های اصلی قابل دسترس نسخه‌های V9 تا V13 است.

## محتویات

- `releases/diamond_ring_spectral_studio_v9.html` — خروجی HTML نسخه ۹؛ محتوای فایل اصلی بدون تغییر است و فقط پسوند `.txt` به `.html` تغییر داده شده تا مرورگر آن را به‌عنوان صفحه اجرا کند.
- `releases/diamond_ring_spectral_studio_v10.html`
- `releases/diamond_ring_spectral_studio_v11.html`
- `releases/diamond_ring_spectral_studio_v12.html`
- `releases/diamond_ring_spectral_studio_v13.html`
- `packages/` — بسته‌های ZIP اختصاصی نسخه‌های ۱۰ تا ۱۳.
- `README_V13_FA.md` — راهنمای فارسی نسخه ۱۳.

## اجرا

فایل HTML هر نسخه را مستقیماً با مرورگر به‌روز باز کنید. برای تجربه بهتر از Chrome، Edge یا Firefox استفاده کنید.

## نکته درباره نسخه‌های قدیمی‌تر

نسخه‌های V1 تا V8 نیز در کتابخانه فایل‌های پروژه نگهداری شده‌اند، اما فایل خام آن‌ها در این محیط قابل خروجی‌گیری ماشینی نبود؛ بنابراین در این آرشیو ادعا نمی‌شود که V1 تا V8 حضور دارند. لینک بسته‌های اصلی آن‌ها جداگانه در پاسخ گفتگو ارائه می‌شود.

## مجوز و حقوق مؤلف

برای کدهای موجود مجوز جدیدی تعریف نشده است. هرگونه اعلان حق نشر یا مجوز بالادستی که داخل بسته‌های اصلی موجود بوده، باید همان‌طور که هست رعایت شود.
