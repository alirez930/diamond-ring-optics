# Diamond Ring Optics

An experimental browser-based reconstruction and optical-rendering study of an animated diamond ring.

## Run the latest build

Open [index.html](index.html) in a modern browser. It is a convenience copy of the V13 standalone HTML snapshot. The canonical release is [V13](releases/v13/diamond_ring_spectral_studio_v13.html).

## Scope and validation

This is a visual and computational experiment, not a certified gemological ray-tracing package. Geometry, dispersion, internal reflections, lighting, and appearance are software approximations. Validation against measured optical data and an independent reference renderer remains future work.
