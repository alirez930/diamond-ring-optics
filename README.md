# Diamond Ring Optics

An experimental browser-based reconstruction and optical rendering study of an animated diamond ring.

## Current build

The repository preserves versioned HTML snapshots under `releases/`. Open the latest release file directly in a modern browser. No build step is required for the standalone HTML experiments.

## Version archive

- **V01–V02** — initial ring and diamond animation.
- **V03–V04** — reference and geometry/rendering refinements.
- **V05–V06** — spectral and smooth-rendering experiments.
- **V07–V10** — spectral studio progression.
- **V11** — first V11 snapshot.
- **V11 revision** — later expanded V11 build, kept separately so neither snapshot is lost.
- **V12–V13** — later studio builds with interaction and lighting refinements.

The archive preserves historical snapshots; it does not imply that every optical approximation has been experimentally validated.

## Scope and validation

This is a visual/computational experiment, not a certified gemological ray-tracing package. Geometry, dispersion, internal reflections, lighting and appearance are approximations. A future milestone is validation against published optical constants and an independent reference renderer.
